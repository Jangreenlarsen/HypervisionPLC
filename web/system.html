IP Access Control (ACL)


Tillad/bloker adgang til HTTP/HTTPS (Web-GUI + REST API + OTA), Telnet eller SSE fra bestemte IP-adresser/subnet (CIDR). Reglerne evalueres i RÆKKEFØLGE — første matchende regel vinder (samme princip som klassiske firewall-ACL'er). Ingen match = tilladt, så en "Bloker"-regel for 0.0.0.0/0 nederst i listen lukker for alt andet der ikke matchede en regel ovenfor. Arbejder som en rigtig firewall: ændringer herunder redigerer en KANDIDAT-konfiguration — intet bliver aktivt før du trykker "Commit ændringer" (kan udløse et bekræftelses-flow via en frisk login, se advarslen nedenfor).







-




Ikke-committede ændringer. Kandidat-konfigurationen herunder er endnu IKKE aktiv — byg og ombyg regelsættet frit, uden risiko for at logge dig selv ude undervejs. Tryk "Commit ændringer" når du er tilfreds (kan udløse samme bekræftelses-flow som hidtil, men kun ÉN gang for alle ændringer samlet), eller "Fortryd alle" for at forkaste dem og gå tilbage til den aktive konfiguration.











Afventer bekraeftelse. Denne aendring paavirker management-adgang (HTTP/Telnet) og er endnu IKKE gemt permanent — alle sessioner er logget ud. Log ind PAA NY og bekraeft nedenfor for at gemme, ellers rulles den automatisk tilbage om -.

Legacy Auth


Bruges når RBAC (Brugerstyring ovenfor) er deaktiveret — ét fælles brugernavn/kodeord for hele REST API'et og web-GUI'et.






"Bearer" lukker helt for at browsere (Firefox m.fl.) kan cache login permanent uden for appens kontrol — men kræver at gamle curl/Node-RED-scripts der bruger -u bruger:pass direkte opdateres til først at hente et token via POST /api/login. Se REST API-referencen.




















HTTPS / TLS


Krypteret adgang til web-grænsefladen. Certifikat/nøgle er indlejret i firmwaren ved kompilering og kan ikke uploades her eller via CLI — kun til/fra og port kan styres, samme betingelser som CLI-kommandoerne set http tls on|off og set http https-port <port>. HTTPS lytter på sin egen dedikerede port — ikke samme port som almindelig HTTP — så det ene ikke holder op med at virke når det andet slås til. Kræver Gem + Genstart for at træde i kraft.
